## 👨‍🔬 About Me

I am a **PhD Researcher in Robotics at the University of Genoa (UniGe), DIBRIS — Department of Informatics, Bioengineering, Robotics and Systems Engineering**.

My research focuses on developing intelligent and autonomous robotic systems by combining **reinforcement learning, computer vision, multispectral perception, sensor fusion, and robot navigation**.

I am particularly interested in robots that can **perceive, reason, and navigate autonomously in complex and dynamic environments**.

## 🚀 Selected Research & Projects

### 🤖 Reinforcement Learning for Autonomous Navigation

Developing reinforcement-learning-based navigation and control methods for mobile robots.

**Technologies:**

`Isaac Lab` · `Isaac Sim` · `SKRL` · `PPO` · `ROS2` · `Nav2` · `Python` · `C++`

Current work includes:

* RL-based local navigation
* Differential-drive robot control
* LiDAR-based perception
* Obstacle avoidance
* Reward design
* Simulation-based training
* ROS2 deployment
* Sim-to-real considerations

---

### 🧍 Human-Aware Robot Navigation

Researching navigation methods for robots operating in environments shared with humans.

Areas of interest include:

* Human detection and tracking
* Human motion modelling
* Sensor fusion
* Human-robot interaction
* Socially-aware navigation
* Collision avoidance
* Data-driven navigation

---

### 🌈 Multispectral Terrain Identification

Developed deep-learning approaches for terrain and environmental identification using multispectral imagery.

The work investigates the use of multiple spectral bands and differential/band-ratio representations for improving terrain classification.

**Technologies:**

`Python` · `PyTorch` · `ResNet-50` · `OpenCV` · `Scikit-Learn` · `Multispectral Imaging`

---

### 🛢️ Oil Leakage Detection

Developed a deep-learning system for detecting oil-contaminated soil using **drone-based multispectral imaging**.

The project explored:

* Multispectral image acquisition
* Spectral-band analysis
* Machine learning classification
* Deep learning
* ResNet-50
* Environmental sensing
* Drone-based data collection

---

### 🤖 Multi-Agent Robotic Systems

Implemented distributed control algorithms for a multi-robot system using **four TurtleBot3 robots**.

The project investigated:

* Consensus algorithms
* Synchronization
* Multi-agent coordination
* Distributed control
* Mobile robot communication

---

### ⚙️ FPGA & Hardware-in-the-Loop Control

Designed a digital control system using FPGA hardware.

Work included:

* Digital PID controller
* PWM generation
* Verilog implementation
* Hardware-in-the-loop concepts
* Embedded control

Also designed and built a **custom CNC machine for PCB drawing**.
